# Timer Runner for Raycast

Rozbudowana komenda do ustawiania timerów, które uruchamiają aplikacje i komendy systemowe.

## Funkcje

- ⏰ Ustawianie timerów z różnymi jednostkami czasu (sekundy, minuty, godziny)
- 🚀 Uruchamianie aplikacji po zakończeniu timera
- 🖥️ Wykonywanie akcji systemowych (shutdown, restart, blokada ekranu, uśpienie)
- 📝 Autosugestie i łatwe zarządzanie
- 👀 Podgląd aktywnych timerów
- ❌ Możliwość anulowania timerów

## Przykłady użycia

- `Timer: 30 min → shutdown` - wyłączenie komputera po 30 minutach
- `Timer: 10 sec → Google Chrome` - otwarcie Chrome po 10 sekundach
- `Timer: 2 h → Lock Screen` - zablokowanie ekranu po 2 godzinach

## Instalacja

1. Sklonuj repozytorium
2. Uruchom `npm install`
3. Uruchom `npm run dev` aby testować lokalnie
4. Zaimportuj do Raycast
